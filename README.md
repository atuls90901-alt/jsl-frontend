This project is a responsive business dashboard website built using React.js and Tailwind CSS as part of a Web Developer interview assignment
The main goal of this project was to create a clean, modern, and fully responsive dashboard that demonstrates frontend development skills, API integration, form validation, and proper project structure.

Features
Authentication Page
Login page with professional UI
Email and password validation
Responsive design
Dashboard
Sidebar navigation
Top header section
Welcome section
Statistics cards
Product/data table
Fully responsive layout
API Integration
Integrated public API for live data
Dynamic product fetching
Loading state handling
Error handling
Contact Form
Full Name field
Email field
Phone Number field
Message field
Proper form validation
Responsive Design
